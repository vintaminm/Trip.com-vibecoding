# 拼途 · 毕业旅行拼团规划

**把散落的人，拼成一次旅行。**

给毕业班用的旅行拼团工具：一个班十几个人、分散在几个城市、预算不一样，也能 3 天把时间、目的地、预算定下来；机票民宿各付各的，没人垫钱；有人退出按约定算，不伤感情。做成携程 App 里的一个入口，用携程已有的机酒库存、价格、退改规则和 AI 行程助手。

- 在线原型（手机和电脑两种布局）：https://vintaminm.github.io/Trip.com-vibecoding/
- 产品设计说明（痛点、结构、流程、机制、指标、路线图、来源）：https://vintaminm.github.io/Trip.com-vibecoding/#/design

## 怎么看这个原型

数据是一个 14 人、3 个出发地的毕业班，每个数字都由成员数据算出来。右上角「演示 ▾」可以跳到任一阶段：

| 阶段 | 页面 | 可以点的 |
|---|---|---|
| 收偏好 | 概览 / 定方案 | 填自己的偏好（日历、预算档位、想去哪、硬约束），一键催没填的人 |
| 定方案 | 定方案 | 三套方案的能来人数、人均、匹配度；投票；看每个出发地怎么合流；组织者锁定 |
| 排行程 | 行程 | 按天看行程，分队日加入小队，给提议点赞，组织者采纳 |
| 各付各的 | 费用 | 机票民宿拆成每人的份，付自己的，提醒没付的人 |
| 出行中 | 行程 | 签到、晚饭投票、记一笔 |
| 结算纪念 | 费用 / 纪念册 | 净额结算每人只转一次；照片时间轴、每人一句话 |

成员页可以演示「有人退出」：按建团时定的出发约定，自动算机票退改、房间差价和受影响的人。

## 产品结构

```
拼途（携程 App 入口 / 小程序 / 网页）
├─ 首页：我的团、建团、邀请码加入、毕业季大家都在去
├─ 团空间（一个团一个，五个阶段自动推进）
│  ├─ 概览：阶段进度、现在要做的事、团里的数、AI 领队、出发约定
│  ├─ 定方案：偏好汇总 → 三套方案 → 投票、折中方案 → 组织者锁定
│  ├─ 行程：AI 草稿 → 成员提议、采纳 → 分队与集合点 → 出行中签到、临时投票、记一笔
│  ├─ 费用：预算对照 → 各付各的 → 行中记账 → 净额结算 → 出发约定
│  ├─ 成员：角色、每阶段状态、退出演算
│  └─ 纪念册：照片时间轴、每人一句话、分享到携程社区、明年再约
├─ AI 领队：汇总偏好、合方案、给折中、排接站、提醒、按约定算退出
└─ 我的：出发城市、证件、支付方式、历史团
```

## 关键设计

1. **能来的人数排在票数前面**：毕业旅行的意义是人齐，方案卡片第一个数字是「13/14 能来」。
2. **少数派意见变成折中选项，不是被否决**：一个人 7/3 走不开，AI 领队给出全团改期或他晚一天到两条路。
3. **各付各的，不做公账**：携程订单按人拆份，各自付、各自退改，平台不碰资金池。
4. **出发约定先定，退出自动算**：机票退多少、室友差价谁担、其他人人均变不变，并通知到人。
5. **分队与集合点**：各队各自日程，集合点统一，集合前 30 分钟提醒。
6. **AI 领队有边界**：它汇总、合方案、提醒、算账；锁定、采纳、退出都由人点，每条建议写明依据。

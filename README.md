# 拼途 · 毕业旅行拼团规划

**把散落的人，拼成一次旅行。**

给毕业班用的旅行拼团工具：一个班十几个人、分散在几个城市、预算不一样，也能 3 天把时间、目的地、预算定下来；机票民宿各付各的，没人垫钱；有人退出按约定算，不伤感情。做成携程 App 里的一个入口，用携程已有的机酒库存、价格、退改规则和 AI 行程助手。

- 在线原型（手机和电脑两种布局）：https://vintaminm.github.io/Trip.com-vibecoding/
- 同学点开邀请链接看到的页面：https://vintaminm.github.io/Trip.com-vibecoding/#/join?stage=collect
- 产品设计说明（痛点、结构、流程、机制、借鉴了谁、指标、路线图、来源）：https://vintaminm.github.io/Trip.com-vibecoding/#/design

## 怎么看这个原型

数据是一个 14 人、3 个出发地的毕业班，每个数字都由成员数据算出来。首页底部有一条三分钟的演示路线；右上角「演示 ▾」可以跳到任一阶段：

| 阶段 | 页面 | 可以点的 |
|---|---|---|
| 收偏好 | 邀请页 / 概览 / 定方案 | 同学点开邀请链接，在名单里点自己的名字加入；填偏好（日历分可以、勉强、不行，预算档位、想去哪、硬约束）；一键催没填的人 |
| 定方案 | 定方案 | 三套方案的能来人数、人均、匹配度，每个出发地各自的价格；谁哪天能来；投票；合流地图；组织者锁定 |
| 排行程 | 行程 | AI 草稿自查（预算、到达与集合、每天景点数、开放时间）；第一天合流地图；分队日加入小队；给提议点赞，组织者采纳 |
| 各付各的 | 费用 | 机票民宿拆成每人的份，付自己的，提醒没付的人 |
| 出行中 | 行程 | 签到、晚饭投票、记一笔 |
| 结算纪念 | 费用 / 纪念册 | 余额条；62 次转账变 13 次，每人只和财务转一次；标记已转到两清；路线、照片时间轴、每人一句话 |

成员页可以演示「有人退出」：按建团时定的出发约定，自动算机票退改、房间差价和受影响的人。

## 产品结构

```
拼途（携程 App 入口 / 小程序 / 网页）
├─ 邀请页：邀请海报、谁已经加入、留言和表情、人越多越省、出发约定、名单里点自己的名字
├─ 首页：我的团、建团、邀请码加入、三分钟演示路线、毕业季大家都在去
├─ 团空间（一个团一个，五个阶段自动推进）
│  ├─ 概览：阶段进度、现在要做的事、关键数字、人越多越省、出发约定
│  ├─ 定方案：偏好汇总（日期热力、谁哪天能来）→ 三套方案（分城价格、合流地图）→ 投票、折中方案 → 组织者锁定
│  ├─ 行程：AI 草稿与自查 → 成员提议、采纳 → 分队与集合点 → 出行中签到、临时投票、记一笔
│  ├─ 费用：预算对照 → 各付各的 → 行中记账 → 净额结算（余额条、标记已转、两清）
│  ├─ 成员：角色、出发城市、室友、每阶段状态、退出演算
│  └─ 纪念册：数据回顾、我们的路线、照片时间轴、每人一句话、分享到携程社区、明年再约
├─ AI 领队：汇总偏好、合方案、给折中、排接站、提醒、按约定算退出
└─ 我的：出发城市、证件、支付方式、历史团
```

## 关键设计

1. **能来的人数排在票数前面**：毕业旅行的意义是人齐，方案卡片第一个数字是「13/14 能来」。
2. **少数派意见变成折中选项，不是被否决**：一个人 7/3 走不开，AI 领队给出全团改期或他晚一天到两条路。
3. **勉强也是一种回答**：日期分可以、勉强、不行三档，勉强算进能来人数，但写在方案卡上。
4. **人越多越省**：满 6 人整栋民宿、满 10 人包车接送站、满 12 人晚宴包间，概览和邀请页都写着还差几人（门槛和金额是设想）。
5. **各付各的，不做公账**：携程订单按人拆份，各自付、各自退改，平台不碰资金池。
6. **出发约定先定，退出自动算**：机票退多少、室友差价谁担、其他人人均变不变，并通知到人。
7. **分队与集合点**：各队各自日程，集合点统一，集合前 30 分钟提醒。
8. **AI 领队有边界**：它汇总、合方案、提醒、算账；锁定、采纳、退出都由人点，每条建议写明依据。

## 借鉴了谁

详细对照在设计说明第 05 节。

- **Partiful**：一个链接一张海报，点开先看到谁已经来了；拼途的邀请页同时是报名入口，加入前先确认出发约定。
- **Rallly、Crab.fit、When2meet**：每天可以、勉强、不行三档，颜色越深空的人越多；拼途把日期和想去哪、预算、玩法一起算进方案。
- **Spliit、Splitwise、Tricount、TREK**：选「我是谁」就能用，净额结算、红绿余额条、两清；拼途的机票民宿在携程各付各的，不进账本。
- **Polarsteps、Wanderlog**：路线画在地图上；拼途画的是三个出发地怎么合流到一个集合点。
- **Mindtrip、ChatGPT 群聊**：AI 合并大家的偏好；拼途的 AI 领队不主动插话，决定由人点。
- **TravelPlanner**：用明确的检查项给 AI 行程挑错；拼途把自查结果写在行程顶部。
- **Google AI 机票特价**只能填一个出发地；拼途每套方案按每个出发地分别报价。
